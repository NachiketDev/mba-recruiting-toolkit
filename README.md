# MBA Recruiting Toolkit

Three small, single-file web tools I built to prepare for consulting recruiting. Each one runs in the browser with no install and no server, and keeps its data in your browser's local storage.

**Try them:** https://nachiketdev.github.io/mba-recruiting-toolkit/

| Tool | What it does |
|---|---|
| [Case interview timer](case-timer.html) | A phase-by-phase timer for mock case interviews (restate, clarify, structure, exhibits, brainstorm, recommendation), with audio and vibration alerts and copyable split times. |
| [Case prep tracker](case-prep-tracker.html) | Logs each practice case, scores ten skills, tracks weekly cadence against a target, and keeps a pre-case checklist and framework notes in one place. |
| [Coffee chat companion](coffee-chat-companion.html) | Prepares a coffee chat with a consultant: firm-specific question order, a 30-second intro template, live notes, and a drafted thank-you note. |

## Why I built them
Case prep generates a lot of loose data: timings, feedback from different partners, and the same mistakes repeating across cases. I wanted each mock case to leave a record I could learn from, without a spreadsheet open during the case.

## Notes
- Everything runs locally. Nothing is sent anywhere.
- The sample case and intro text are placeholders. Replace them with your own.
- Built with plain HTML, CSS and JavaScript.
